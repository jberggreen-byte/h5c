# h5c.dk – High 5 Classics

Static copy of https://h5c.dk (previously on Dandomain's website builder), made 21 Nov 2026.

- Preview: https://jberggreen-byte.github.io/h5c/
- All links are relative, so the site works both under /h5c/ and at the root of h5c.dk.
- `CNAME.pending` → rename to `CNAME` when DNS for h5c.dk is pointed at GitHub Pages.
- Images, CSS, JS and fonts are local under `assets/` (files = Dandomain file storage, res = builder runtime, gfonts = Google Fonts).
- Not working statically: the newsletter signup form "Bliv opdateret" on the blog pages (posted to Dandomain's `/_bk/submit-form`).
